# STRETCH: radiocarbon dating with a tight interval

This has the same model and measurement as `radiocarbon`. The upper bound 11 798 years is within 0.6 years of the
exact age at f = 0.24, so the proof needs log 2 and log(25/24) to about four significant digits. Mathlib's
precomputed `log 2` bounds module is not available in this checker's import set. The task probes where the agent
loop stops; an unfinished result is a legitimate outcome.
